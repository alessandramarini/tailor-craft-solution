Il tuo Database Gratuito (Come funziona?)

Questo programma è stato creato per essere gratuito. Tutti i clienti che salvi vengono memorizzati SOLO nel tuo computer (nella memoria del browser).


⚠️ ATTENZIONE: Se formatti il dispositivo o cancelli la cronologia di navigazione, perderai i clienti salvati!

LA SOLUZIONE: Usa il pulsante "🗄️ Cassa Forte Dati" in alto. Ti permette di scaricare un piccolo file con tutti i tuoi clienti. Quando vuoi, puoi "importarlo" per riavere tutta la tua rubrica.

Come usare l'App passo dopo passo:

  1. Crea l'idea (Fase 1): Scegli il vestito. L'app creerà un Prompt. Incollalo nell'Intelligenza Artificiale (es. Midjourney) per il disegno.
  2. Prendi le misure (Fase 2): Misura la tua cliente. Scrivi il suo nome in alto. Premi "SALVA".
  3. Preventivo (Fasi 3 e 5): L'app fa i calcoli magici per i metri di stoffa e i costi. Genera il PDF e il messaggio WhatsApp.
  4. Genera il Cartamodello (Fase 4): Scaricherà un file ".vit". Usalo dentro il programma gratuito Seamly2D per stampare il cartamodello.

Cosa devi fare ora? (Leggi bene)

Il file si trova nella cartella "Download" del tuo computer.

Questo file non puoi aprirlo facendoci doppio clic. Devi usare il programma CAD per sarti.

  1. Se non lo hai, scarica e installa gratis il CAD per sarti da qui: www.seamly.net
  2. Apri il programma chiamato SeamlyMe (si installa insieme a Seamly2D).
  3. Dentro SeamlyMe vai in alto a sinistra, clicca File > Apri.
  4. Scegli il file che hai appena scaricato da qui. Fatto! Avrai il cartamodello su misura.
